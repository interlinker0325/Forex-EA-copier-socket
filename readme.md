# EA-copier using ZMQ websocket
EA-copier is a forex tool for automatically copying trades between MetaTrader terminals. This project implements an EA auto copier using the ZMQ library to enable socket communication between a master and slave EA, making it easy to synchronize trades from one account to another in real time.
